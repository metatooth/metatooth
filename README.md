# Metatooth

This is the mono repository for Metatooth LLC. It's supposedly a good idea.

## baldur

A Sinatra + ROM image gallery application for managing and displaying artist
portfolios, built for [laramirandagoodman.com](https://laramirandagoodman.com).

## deploy

Ansible playbooks for host maintenance, shared across projects (package
upgrades, reboots).

## herbert

A thermostat controller that reads a SwitchBot Meter over Bluetooth and
switches a Meross smart plug to control a heater.

## kaleidocycle

An Express app for [kaleidocycle.metatooth.com](https://kaleidocycle.metatooth.com),
visualizing a kaleidocycle: a ring of tetrahedra that rotates about itself.

## magento

The Magento e-commerce shop deployed to
[shop.metatooth.com](https://shop.metatooth.com), running PHP-FPM + Nginx in
Docker.

## metalogo

Generates the Metatooth logo and related brand assets using OpenSCAD.

## multidraw

A C++ application framework implementing Unidraw, a framework for building
domain-specific graphical editors, built on FLTK.

## openspec

Spec-driven change management configuration for this repository.

## wordpress

A shared Ansible deployment project for WordPress sites (Docker Compose +
Nginx), currently used to deploy [lynngrown.com](https://lynngrown.com).
